# RidePlay 屏幕方向锁定

入口：设置首页 → 快捷设置 → 屏幕方向，也保留设置 → 显示 → 屏幕方向。两处共用同一配置和确认流程。选项为自动、横屏、竖屏；默认自动。

快捷设置保持四项：打开应用时连接、日夜模式、全屏、屏幕方向。位置上报的完整设置仍在导航页。

用户已反馈方向锁定有效。后续手机操作由用户完成。

- 作用于首页、设置和 CarPlay 界面（包括同任务 CarPlay 窗口）。设置持久保存，重新打开时继续应用。
- 只设置应用 Activity 的方向，不修改 Android 全局自动旋转、用户方向或其他应用。
- 自动模式恢复每个界面的上游方向策略：主界面为系统默认，CarPlay 窗口为原有 fullSensor。它与高级设置中的 CarPlay 旋转编码/画布功能独立。
- 有活动 CarPlay 会话时，更改选项使用原有的“应用并重新连接”确认按钮；取消不保存，不静默断开。
- 默认恢复自动即可回退，无需清除数据或卸载应用。
