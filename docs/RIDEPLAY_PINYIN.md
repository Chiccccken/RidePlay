# 歌名与歌手的离线拼音

入口：设置 → 高级 → 歌曲信息拼音（实验性）。默认关闭，下次 CarPlay 连接生效。关闭并重连恢复原文。

只在 Android MediaSession 的发布边界转换 title、artist 及对应 display 字段；可选的“专辑名拼音”开关默认关闭，启用后也转换 Android 的 album 字段；不改 iPhone 原始 Now Playing 模型、CarPlay 画面、原始专辑信息、封面、播放状态、进度或 HID 控制。Android 媒体卡片和其他读取同一会话的应用也会看到拼音，无法只对 KTM 单独提供另一套文字。

使用 Android 10/API 29 起公开提供的 ICU Han-Latin 转换，在设备上完成，无在线服务或新增大型依赖。低版本隐藏设置，转换器保留原文。ICU 转换不可用或异常时保留原文。每条信息只在内容更新时转换，内存缓存最多 128 条，不记录歌曲日志或写入磁盘。

汉字转换为首字母大写、不带声调的拼音；ü 用 ASCII v 表示。原有英文、数字、符号、重音字母与 emoji 保留，在相连汉字/英数之间加入空格。小型离线词典优先纠正重庆/重慶、银行/銀行、音乐/音樂、长安/長安、单依纯和曾轶可；其他词交给系统 ICU。

## 副作用与限制

- 红米媒体卡片和其他系统媒体监听者也显示拼音。
- 人名、多音字、粤语等发音不保证正确；词典是有限的纠正规则，不是完整姓名或语言识别系统。
- 含日文平假名/片假名的整条文字保留；仅由汉字构成的日文名称仍可能被当作中文。
- 拼音往往比汉字长，KTM 可能截断或滚动显示；具体行为待实车验证。
- 不改变音频路由或音频焦点策略；开启或关闭后要重新连接，当前连接不会被静默中断。

自动测试覆盖中英混合、多音词、空值、重音字母/emoji、旧系统回退、默认关闭、元数据发布边界，以及媒体按键回归。完整 CI 和真实手机/仪表显示结果需分别记录，不能以本地转换成功代替 KTM 验收。

## 专辑和自定义歌手名称

“专辑名拼音”依赖主拼音开关，开启后下次连接将 Android MediaSession 的专辑名也转成拼音；CarPlay 画面中的专辑原文保留。KTM 是否显示专辑字段仍未实测。

“歌手名称替换”同样依赖主拼音开关：添加 iPhone 给出的完整原歌手名与希望显示的名称。例如 `想想XiangXiang` → `Xiang Xiang`。按完整名称精确匹配（保留大小写，忽略首尾空格），替换内容原样发布、优先于自动转换；不做模糊匹配或自动猜测中英文是否重复。不同拼写需要分别添加规则。

规则只保存在应用本地，最多 100 条，每个名称最多 200 个 UTF-16 代码单元。编辑已有规则时原名固定；显示名留空并保存会删除规则。更改规则下次 CarPlay 连接生效。关闭主拼音开关可暂时停用全部规则，不删除其配置。
